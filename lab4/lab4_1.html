Перші кроки з CSS

CSS – це формальна мова декорування та опису зовнішнього вигляду веб-сторінки, написаної за допомогою мови розмітки HTML. CSS використовується для задання кольорів, шрифтів, стилів, розташування та інших аспектів представлення зовнішнього вигляду веб-сторінок. Основною метою CSS є відокремлення опису логічної структури веб-сторінки від її зовнішнього вигляду.

Додаткова інформація про CSS

Призначення каскадної таблиці стилів CSS: забезпечує гнучкість та сумісність при оформленні веб-сторінок.

Принципи застосування таблиці стилів CSS: стилі застосовуються каскадно відповідно до їх пріоритетів.

Синтаксис утворення правила CSS

Структура таблиці CSS: складається зі списку правил и селекторів.

Правило CSS: визначає, до яких елементів застосовуються стилі.

Структура елемента таблиці CSS: властивість та значення, відокремлені двокрапкою.

Селектори CSS: вказують на конкретні теги, класи або ідентифікатори.
